# Dental Clinic Management System

A web-based dental clinic management system developed to manage patients, doctors, appointments, treatments, and user accounts through a centralized application.

## Features

- User registration and authentication
- Patient management
- Doctor management
- Appointment scheduling and management
- Treatment management
- CRUD operations
- Admin dashboard
- Relational database for storing and managing clinic data
- Role-based access to different parts of the system

## Technologies Used

- **PHP** – Backend development and server-side logic
- **MySQL** – Relational database management
- **HTML** – Application structure
- **CSS** – Styling and user interface
- **JavaScript** – Client-side functionality

## Database

The application uses a MySQL relational database designed to manage and connect data related to:

- Users
- Patients
- Doctors
- Appointments
- Treatments
- Other clinic-related records

Relationships between entities allow the system to efficiently organize and retrieve clinic information.

## Project Structure

The project is organized into separate components for handling the application's pages, database operations, authentication, and user interface.

## Purpose

This project was developed as a practical application of web development and database concepts, with a focus on building a functional system backed by a relational database.
